# Analytics

Planned technology: **Python**.

The analytics layer processes raw SUMO simulation output into measurable, comparable metrics — travel time, delay, queue length, average speed, throughput — and computes calibration/validation error against observed traffic data. See [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for how this component fits into the overall system.

## Status

Not yet implemented. No analytics code exists in this repository. This layer is built after a working, calibrated baseline simulation exists (see [`../docs/PROJECT_STATUS.md`](../docs/PROJECT_STATUS.md)).
