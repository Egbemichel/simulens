# Frontend

Planned technology: **Next.js, React, TypeScript**, with **Three.js** for 3D visualization.

The frontend will be the user-facing application for configuring scenarios, viewing analytics comparisons, and — later — exploring the corridor's 3D visualization. See [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for how this component fits into the overall system.

## Status

Not yet implemented. No frontend code exists in this repository. Per the project's principles, 3D visualization and its supporting UI come after the simulation foundation is working and validated (see [`../docs/PROJECT_STATUS.md`](../docs/PROJECT_STATUS.md)).
